**Task2-To-Do-App**
The Advanced To-Do List App is a mini interactive JavaScript application built using HTML, CSS, and JavaScript with extensive DOM manipulation techniques.
**Project Description:-**
The Advanced To-Do List App is a mini interactive JavaScript application built using HTML, CSS, and JavaScript with extensive DOM manipulation techniques. The application helps users manage daily tasks efficiently through features like task creation, editing, deletion, filtering, searching, and task status tracking. The project demonstrates how JavaScript dynamically interacts with webpage elements without reloading the page. It provides a responsive and user-friendly interface where users can organize tasks effectively.
